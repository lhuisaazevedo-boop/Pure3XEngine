# 🧠 Fluxo de Revisão de Código — Pure3XEngine

> Antes de qualquer commit, o código passa por múltiplas revisões.
> Nenhuma IA é infalível. A combinação de diferentes análises aumenta a chance de encontrar problemas.

## 🔁 Processo de desenvolvimento

1. 📝 Escrever ou modificar o código
2. 🔍 Primeira revisão → Identificar erros
3. ✨ Segunda revisão → Sugerir melhorias
4. ⚖️ Comparar e avaliar as sugestões
5. 🛠️ Aplicar apenas as alterações aprovadas
6. 🧪 Compilar e testar o projeto no ambiente real (Termux/Android)
7. 💾 Somente então realizar o commit

## 🤖 Perfis úteis para o P3XE

| IA | Costuma ajudar mais em |
| --- | --- |
| ChatGPT | Arquitetura, Bash, Git, CMake, revisão de código e integração entre módulos |
| Qwen | NDK, SDK, Gradle, compilação e configuração de ferramentas |
| Gemini | Sintaxe C++/JNI, avisos do compilador, análise de erros locais e revisão de código |
| Outras | Novas abordagens, alternativas de implementação e validação cruzada |

## ⚠️ Regra de ouro

> **Nenhuma IA substitui a compilação e os testes reais.**
>
> Se o projeto não compilou no Termux e não executou corretamente, ele ainda não está pronto.
